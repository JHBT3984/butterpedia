# 나비도감 · BUTTERFLY ARCHIVE

무엇이든 나비가 될 수 있다는 아이디어를 담은 반응형 공개 아카이브입니다. 첫 화면부터 표본 보드와 분류 탐색이 보이는 에디토리얼 아카이브 레이아웃입니다. 정적 파일만으로 미리보기 모드를 실행할 수 있고, Supabase를 연결하면 사진과 기록이 공용으로 저장됩니다.

## 로컬에서 보기

프로젝트 폴더에서 간단한 정적 서버를 실행한 뒤 `http://localhost:8000`을 엽니다. 첫 화면의 나비를 누르면 `archive.html`의 표본 인덱스로 이동합니다.

```sh
python3 -m http.server 8000
```

서버 없이 `index.html`을 직접 열면 브라우저의 보안 정책 때문에 사진 업로드가 제한될 수 있습니다. Supabase 설정 전에는 `localStorage`를 사용하는 미리보기 모드로 작동합니다. 미리보기 기록은 현재 브라우저에만 저장됩니다.

## 공개 아카이브 연결

1. Supabase 프로젝트를 만듭니다.
2. Dashboard의 **SQL Editor**에서 `supabase-setup.sql` 내용을 실행합니다. 이 파일은 공개 열람과 익명 업로드를 허용하므로, 공개 아카이브로 배포할 때에만 사용하세요.
3. 프로젝트 URL과 **anon/public key**를 `config.js`의 `url`, `anonKey`에 입력합니다. `service_role` 키는 절대로 브라우저 코드에 넣지 마세요.
4. `index.html`, `archive.html`, `styles.css`, `app.js`, `config.js`, `assets/`를 HTTPS 정적 호스팅에 배포합니다. Vercel, Netlify, GitHub Pages 등 정적 호스트를 사용할 수 있습니다.

Supabase에 연결한 뒤 모든 방문자는 같은 공개 기록을 보며, 새 기록도 공용 데이터베이스와 사진 저장소에 올라갑니다. 분류는 문자열로 저장되므로 새 분류는 폼에서 바로 만들어집니다. 별도 계정이나 서버 런타임은 필요하지 않습니다.

## 포함 기능

- “세상의 모든 나비” 소개 표지와 나비를 눌러 들어가는 별도 표본 인덱스
- 표본 사진의 크기와 높이를 달리한 3열 자유 그리드, 모바일 2열 배치
- 실제 나비, 포장지, 그림자, 종이 표본으로 채운 로컬 미리보기 보드
- 모바일 카메라 입력, 파일 선택, 드래그 앤 드롭
- 페이지 안 카메라 미리보기와 촬영, 브라우저 미지원 시 기기 카메라 대안
- 이름, 단일 카테고리 선택/생성, 특징과 이야기 입력
- 공개 아카이브 목록, 카테고리 필터, 검색, 상세 보기
- 이미지 축소 및 JPEG 변환, 8MB 업로드 제한
- Supabase 연결 전 미리보기 모드, 로딩/오류/빈 목록 안내, 저장 알림
- 작은 화면을 포함한 반응형 레이아웃

## 공개 제출에 관한 메모

SQL 정책은 회원 가입 없이 누구나 읽고 제출할 수 있게 설정되어 있습니다. 스팸/악용 방지나 제출자 관리가 필요한 운영 환경이라면 Supabase Auth, CAPTCHA, 제출 빈도 제한과 검토 절차를 추가하세요.
